# 标注质量与数据用途评测

事实标注分别计算事件精确率/召回率、时间段重合、对象身份一致率、数值误差、`unknown` 的正确使用率；3D 第一人称另按遮挡、镜头运动和视角差异切片。模型预标注与人工参考标签分开报告。

专家判断先看依据是否回链已确认观察，再看不同专家对结论、严重程度与适用条件的一致性。分歧不是一律错误：记录争议类型与仲裁结果，保留仍未解决的多解情形。抽样复查已批准案例，监测版本变化后判据是否失效。

数据集检查同一对局、同一玩家、同源录像的相邻片段是否跨 train/dev/test；检查测试集是否被用来改 Prompt、补知识或挑模型。验收时分别报告感知标签、专业判据和端到端教练效果，不把专家标注完成率写成模型准确率。
