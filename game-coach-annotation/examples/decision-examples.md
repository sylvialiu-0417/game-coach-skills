# 三个标注输入输出示例

示例均为虚构内容，展示标注结构和回退方式，不构成真实游戏攻略。

1. **可复核的战术判断**：输入为玩家第一视角录像及当前版本目标。先标“第 42 至 45 秒离开掩体、准星移动轨迹”，附画面时间；专家再写“在该目标和可见威胁下，预瞄准备不足”，说明判据和“快速转点时可能合理”的例外。事实与判断保存为两条记录。
2. **缺上下文的装备截图**：输入只显示装备面板属性，缺玩家流派和关卡目标。事实可标截图文字；专家判断设为 `insufficient_evidence`，不标“最优装备”。补足构筑信息后才能重新审定。
3. **专家意见不一致**：两位专家对同一走位给出不同解释。保留双方对可见事实、目标和风险的依据，状态为 `disputed`；领域负责人裁定前不将其加入线上判据或独立测试集。
