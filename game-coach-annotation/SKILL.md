# 游戏教练专家复盘标注

## 目标与适用判断

把专家看录像时的“看到了什么”和“为什么这样判断”分开保存，让结果可用于感知评测、教练知识改进或训练数据制作。开始前确认游戏、规则版本、玩法模式、视角、媒体使用授权和标注目标。任一项不明时先登记缺口；未经确认的录像不进入训练或发布流程。字段见 [标注契约](references/contracts.md)。

本 Skill 用于**离线标注生产与审定**。它不直接分析实时对局，也不把一位专家的意见写成游戏规则。`game-coach-perception` 可提供机器预标注；人工复核后形成观察标签。`game-coach-kb` 只使用审核通过的判据或案例。三者的交接见 [工作流程](references/workflow.md)。

## 执行与检查点

1. **登记样本**：记录媒体 ID、来源及授权、`game_id/ruleset_id/mode_id`、视角和全局时间。按场景、水平段与失败类型取样，避免只标精彩片段。未经授权的观战隐藏信息不标成玩家可见事实。
2. **核对事实**：读取机器预标注或手工检查片段，逐条确认对象、状态、行为与时间段；附可回放的证据定位。看不清、听不清或视角缺失时标 `unknown`，不要把预标注直接当作参考标签。
3. **写专家判断**：基于已核对事实写结论、理由、适用前提、例外与替代打法；引用当前版本专业判据。缺队友信息、游戏目标或战斗日志时写 `insufficient_evidence`，不强行归因。示例见 [输入输出示例](examples/decision-examples.md)。
4. **独立复核**：用于发布判据或参考评测的案例交另一位领域专家审阅；分歧记录双方依据并仲裁，不用多数表决替代证据。检查相邻视频切片是否重复标记同一事件。
5. **分流产物**：事实标注进入感知训练或评测数据；专家判断进入待审判据与案例库；训练集、调参集、独立测试集按对局及玩家隔离。任何案例进入线上知识库须经独立发布流程，不能因本 Skill 标为 `approved` 就自动发布。

运行 `python3 scripts/validate_package.py` 检查结构与示例；按 [标注质量评测](references/evaluation.md) 检验一致率、时间定位、分歧和数据泄漏。结构检查不能证明专家判断正确。
