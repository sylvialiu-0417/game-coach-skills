# 三个 Skill 的职责与交接

线上使用与离线专家生产是两条互相连接的流程。

## 线上使用

![线上教练调用流程](figures/online-coaching-flow.png)

1. 宿主提供可信的游戏、规则版本、玩家授权与教练配置。
2. 观察 Skill 把输入整理为有证据位置的观察包，保留视角和不确定性。
3. 知识教练 Skill 检索当前规则与已发布专家判据，检查建议前提。
4. 宿主按延迟、展示与打断策略决定是否将建议交给玩家。

## 专家复盘生产

![专家复盘标注与数据分流](figures/expert-annotation-flow.png)

1. 登记素材来源、授权、版本、视角、时间与抽样原因。
2. 观察 Skill 给出机器预标注；专家回看原证据，核对事实。
3. 专家在事实基础上记录判断、理由、前提、例外与替代方案。
4. 对拟发布判据和参考评测答案独立复核，保留争议与仲裁记录。
5. 按对局与玩家隔离 train/dev/test，用途登记后分别进入感知数据、知识候选和独立评测。

## 交接约束

事实标签描述可观察内容；专家判断评价其在指定目标下是否合理；教练建议还需验证当前局势。`approved` 是标注审定状态，后续知识发布仍须走独立审核。测试集不得回流训练、提示词调试或知识补充。
