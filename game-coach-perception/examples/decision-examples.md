# 三种观察输入输出

这些例子是虚构测试素材。`ObservationBundle` 的完整结构见 JSON 示例。

1. **可信事件接口**：输入为已授权的本局事件，记录玩家资源值 30。输出该值为 `observed`，附事件 ID、时间和玩家视角；不解释应该如何使用资源。
2. **2D 界面截图**：OCR 看见“防御 +12”，输出可见文字和截图区域；隐藏词缀列入 `missing_fields`。不要把没显示的属性记成零。
3. **3D 第一人称音频**：听到左侧疑似脚步声，输出 `inferred` 的方向线索和音频时间段；敌人身份与世界坐标保持未知。单凭声音不能宣称敌人“就在左边墙后”。
