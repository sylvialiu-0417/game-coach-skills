# 感知独立评测

用各游戏合法取得的标注录像或事件轨迹做金标，至少分 2D/3D、玩家/观战视角、实时/离线、不同 HUD、分辨率、规则版本与遮挡程度。训练或调参样本与测试样本分开；接入新游戏时重新校准，不沿用旧游戏的准确率。

事件看精确率、召回率与时间段重合；状态看数值误差、实体身份准确率、角色归因和连续追踪；`observed/inferred/unknown` 看校准、正确拒答及漏报。报告 P50/P95 延迟和资源成本。3D 第一人称另测镜头运动、遮挡、方位和跨帧对象身份；不能只用静态截图准确率推断局内可用性。

和game-coach-kb 做两层对照：A 使用金标观察，B 使用模型观察，知识与决策配置相同。A 错说明教练判断/知识可能有问题；A 对 B 错才优先查感知。再做端到端用户体验评测，观察提示及时性和打断成本。可参考 [GameplayQA](https://aclanthology.org/2026.acl-long.1585/) 对 3D 多主体视频中时间、角色和状态错误的分解，以及 [Video-Arena](https://arxiv.org/abs/2610.14158) 对事件、状态更新和状态追踪的分层测试。两个研究是评测方法参考，不是本 Skill 的性能证据。
