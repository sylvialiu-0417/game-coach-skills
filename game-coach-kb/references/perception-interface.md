# 感知与知识判断的接口

`game-coach-perception` 将获授权的游戏 API、录像、截图或音频转成 `ObservationBundle`。本 Skill 只接收由可信服务提供的结构化观察；不得把画面中看似存在的敌人、技能状态或 3D 世界坐标补成事实。观察包包含 `game_id/ruleset_id/session_id`、全局时间或时间段、视角、观察类型、值、证据定位、来源模态、可见性、`observed/inferred/unknown`、缺失字段和感知版本。

连接时先验证游戏与规则版本一致，再检查观察时间、来源、玩家可见性及关键字段。`inferred` 只能作为假设，不能满足需要直接观察的策略前提；状态过期或证据定位丢失时回退。若同一事实从游戏 API 与视频识别冲突，记录冲突并按游戏团队批准的来源策略处理，不由模型凭语气挑选。

感知层不输出“应该进攻”“这一波失误”。专业教练判断从观察包与已发布的战术判据共同产生。复盘报告中的每条结论必须回链到片段时间、观察 ID、判据 ID；跨回合的习惯判断要先合并重复事件，不能把同一失误在相邻切片中重复计数。

无需视觉的游戏直接用可信状态 API；只有录像而没有 API 的情况可用视频感知，但要独立评测识别准确性。3D 第一人称场景另测遮挡、镜头运动、对象身份延续和方位误判。[观察包 Schema](../schemas/observation-bundle.schema.json) 随两包各自携带，跨包发布前校验版本和内容一致。
