# 专业知识与分层复盘

职业教练录像、战术笔记和标注的“为什么”可形成高价值训练与评测素材，但不能直接当作所有版本、模式和水平段的规则真理。由独立的 `game-coach-annotation` 先区分事实标签与专家判断，记录原作者、授权范围、适用版本、反例和复核人；专业判据经知识发布流程审定后，本 Skill 才可检索。专家意见冲突时并列展示并交领域负责人裁决。

按游戏和任务选择观察维度，不把 FPS 的准星、身法维度写成所有游戏的默认指标。一个专项分析器只评价自身可见且有判据的维度；可采用多个分析器并行，也可在低成本场景用一个模型完成多个维度。拆分本身不会自动消除幻觉，仍需证据定位、交叉检查和人工评测。

复盘按事件/片段 → 单场 → 多场训练计划递进。底层输出事实观察和局部诊断，上层只汇总有证据的模式；每次聚合保留原事件 ID、时间、视角和判据，并对相邻切片重复事件去重。若多场样本不足，只给本场改进建议，不贴长期习惯标签。

局内建议与赛后分析有不同预算：局内只给能在当前时限内验证的短建议，超时静默；赛后允许多模态精查与专家级解释。玩家可选择是否启用、提示频率和表达强度；在探索型游戏中优先保留玩家自主发现空间。长期偏好或历史表现属于玩家档案，须获授权并与当前游戏事实、知识库条目分开存储和过期管理。
